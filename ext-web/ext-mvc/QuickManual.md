## 🔗 HTTP 请求方法一览表

HTTP请求方法定义了客户端与服务器之间的交互方式，以下是常用HTTP方法的详细说明：

| 方法	     | HTTP请求方法定义了客户端与服务器之间的交互方式，以下是常用HTTP方法的详细说明： | 	安全性 | 	幂等性	 | 请求体 | 	示例                     |
|---------|---------------------------------------------|------|-------|-----|-------------------------|
| GET	    | 请求指定的资源，返回实体主体                              | 	是   | 	是    | 	否	 | GET /api/users          |
| POST	   | 向指定资源提交数据，请求服务器进行处理	                        | 否	   | 否	    | 是   | 	POST /api/users        |
| PUT	    | 向指定资源位置上传其最新内容，替换整个资源	                      | 否	   | 是	    | 是	  | PUT /api/users/1        |
| DELETE	 | 请求服务器删除指定的资源                                | 	否   | 	是	   | 否	  | DELETE /api/users/1     |
| PATCH	  | 对资源进行部分修改	                                  | 否	   | 否	    | 是   | 	PATCH /api/users/1     |
| HEAD	   | 类似于GET，但只返回响应头，不返回实体主体                      | 	是   | 	是	   | 否   | 	HEAD /api/users        |
| OPTIONS | 	请求服务器支持的HTTP方法                             | 	是	  | 是	    | 否	  | OPTIONS /api/users      |
| CONNECT | 	建立到服务器的隧道连接                                | 	否   | 	否	   | 否	  | CONNECT example.com:443 |
| TRACE	  | 回显服务器收到的请求，用于诊断	                            | 是    | 	是    | 	否  | 	TRACE /api/users       |

> 关于 HTTP 请求方法
>
> HTTP请求方法是客户端用来向服务器发出请求的动作指令。安全方法指不会改变服务器状态的方法，幂等方法指多次执行相同请求会产生相同结果的方法。了解这些方法的特性对于正确设计和实现RESTful
> API至关重要。
