# ext-library 品牌设计指南

## 标识概念

标识是一个 2×2 的模块网格，其中一格是空的：

```text
┌────────────────────┐
│  ▣     ▢           │
│                    │  ▣ 已装入的模块（实心）
│  ▣     ▣           │  ▢ 空槽：等待接入的扩展模块（描边）
└────────────────────┘
```

- **三格实心** = 已经写好、随取随用的模块
- **一格空心** = 留给使用者接入自己的那一块，也呼应 ext 的本意——把括号/作用域撑开，往里塞东西

四格等分、形状一致，只有"实心 / 空心"这一个变量。信息量最小，但一眼能读懂：这是一个模块集合，且它还能继续长。

标识不含任何文字，不依赖字体渲染，因此在任何尺寸、任何环境下都保持一致，也便于单色化用于打印、激光雕刻等场景。

## 色彩系统

标识本身不带底板，直接放在页面背景上，因此三个文件各自针对所在背景选用前景色：

| 背景               | 实心模块  | 强调模块 | 空槽描边        |
|--------------------|-----------|----------|-----------------|
| 深色（网站、文档） | `#e2e8f0` | 青色渐变 | `#e2e8f0` @ 45% |
| 浅色               | `#312e81` | 青色渐变 | `#312e81` @ 40% |

```css
/* 强调模块（两版一致） */
background: linear-gradient(135deg, #22d3ee 0%, #06b6d4 100%);

/* favicon 沿用品牌主色，适合浏览器工具栏这类深浅不定的环境 */
background: linear-gradient(135deg, #6366f1 0%, #8b5cf6 100%);
```

三格实心里有一格用强调色（不是三格都同色），让"可替换的模块"和"被替换的模块"之间有视觉层次。

| Accent Alt  | `#06b6d4` | 强调模块渐变终点           |

## 文件

| 文件            | 画布    | 用途                           |
|-----------------|---------|--------------------------------|
| `logo.svg`      | 174×174 | 网站、文档、社交媒体（深色底） |
| `logo-dark.svg` | 174×174 | 浅色底场景                     |
| `favicon.svg`   | 64×64   | 浏览器标签页、书签             |

### 几何规格（174×174 画布）

无底板，画布即网格区域。四格边长 77、圆角 22，位于 `x,y ∈ {5,92}`，格间距 10。

| 元素         | 规格                       | 填充                      |
|--------------|----------------------------|---------------------------|
| 网格 (5,5)   | 77×77 rx=22                | 实心                      |
| 网格 (92,5)  | 72×72 rx=19.5 @ (94.5,7.5) | 空心描边 `stroke-width=5` |
| 网格 (5,92)  | 77×77 rx=22                | 青色渐变                  |
| 网格 (92,92) | 77×77 rx=22                | 实心                      |

空槽的描边宽度取 5，略细于填充格的视觉边界，避免与实心格争夺注意力。

SVG 描边默认以路径为中心线向内外各扩展一半，因此空槽不能直接用
77×77：直接画会让它的可见外沿比相邻实心格多出一圈描边，看上去"格外大"，画在画布边缘时还会被裁掉一半。正确做法是把空槽 rect
向内缩半个描边宽（5/2 = 2.5）：尺寸改为 `77-5 = 72`，圆角同步改为 `22-2.5 = 19.5`，位置偏移 2.5。这样描边的 ink 外沿正好落在
`92..169`，与实心格边界严格对齐。

64×64 版本缩放为格 23×23 rx=7、位置 `x,y ∈ {5,36}`，描边加粗到 `stroke-width=9`——小尺寸下描边太细会消失，因此按同样的规则内缩
4.5：空槽为 14×14 rx=2.5 @ (40.5,9.5)。

## 使用

```html
<!-- 深色底 -->
<img src="assets/logo.svg" alt="ext-library" width="120">

<!-- 浅色底 -->
<img src="assets/logo-dark.svg" alt="ext-library" width="120">
```

无底板意味着图形直接压在页面背景上，换背景时不需要改 SVG，只需换用另一个文件。单色场景（如 README
打印版）把三格实心填成同一前景色——"实心 / 空心"的对比仍然成立。

## Banner

启动横幅 (`banner.txt`) 使用 ANSI 彩色输出：

```text
    ███████╗██╗  ██╗████████╗
    ██╔════╝╚██╗██╔╝╚══██╔══╝   (青色)
    █████╗   ╚███╔╝    ██║
    ██╔══╝   ██╔██╗    ██║
    ███████╗██╔╝ ██╗   ██║
    ╚══════╝╚═╝  ╚═╝   ╚═╝      LIBRARY (绿色)
```

| 元素     | ANSI 颜色      |
|----------|----------------|
| EXT 文字 | `BRIGHT_CYAN`  |
| LIBRARY  | `BRIGHT_GREEN` |
| 信息框   | `WHITE`        |
| 特性标签 | `CYAN`         |
| 版本号   | `GREEN`        |
| Emoji    | 各色           |
